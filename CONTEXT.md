# Solstice

The shared language for a calm view of time across the places and people someone cares about.

## Language

**Solstice**:
The product as a whole, including its extension and website.
_Avoid_: World clock extension when referring to the whole product

**Extension**:
The Chrome new-tab experience that shows the user's zones, daylight, working hours, and a shared timeline.
_Avoid_: Website, landing page

**Website**:
Solstice's public web presence. Its home page runs the extension's new tab in the browser, with an Add to Chrome call to action. It may contain other interactive tools over time.
_Avoid_: Marketing site, web app when referring to the whole site

**Web app**:
The interactive tools within the website that let visitors explore time and daylight without installing the extension.
_Avoid_: Landing page, extension

**Zone**:
A place the user cares about, represented by a label, time zone, and coordinates for daylight calculations.
_Avoid_: Clock, location, timezone card

**Local zone**:
The zone anchored to the browser's current time zone and, when available, the user's detected location.
_Avoid_: Home zone, default zone
